# 版本说明 · v1.0.0

发布日期：2026-10-09　｜　交付形态：源码归档 + Git 标签 `v1.0.0`

## 这一版包含什么

一个可运行的 Atoms Demo：一句话描述需求 → 由 AI 团队（产品经理 / 架构师 / 工程师 / 质检）协作生成应用 → 在 App Viewer 里立刻可交互 → 数据实时落库 → 继续对话迭代 → 发布成公开链接。

**核心流程**
- 注册 / 登录 / 一键体验（邮箱 + scrypt 加盐哈希，httpOnly Cookie 会话），工作区自动初始化
- 需求 → 方案 → 流式生成 → 静态质检（不通过自动修复一轮）→ 实时预览
- 数据持久化：生成物通过注入的 `atoms.store` 写入服务端（SQLite / Upstash Redis 双驱动）
- 对话式迭代、版本历史与回滚、导出可独立运行的单文件 HTML
- 发布成 `/p/<slug>` 公开链接，访客可匿名使用；支持一键「复刻」到自己的账号
- 运行时自检：生成物在浏览器里抛错会回传宿主，触发质检 Agent 二次修复
- 模型可在界面内配置（6 家服务商预设 + 连接测试自检），Key 仅存服务端、只回掩码

**双模式**
- 接入真实模型时由模型生成（实测：首字 ~2s，22–45s 产出 20KB+ 完整应用）
- 未接入时走内置生成器：数据台账 / 小游戏 / 展示型站点三类，主流程完整可用；超出范围的需求会如实告知而不是硬编产物

## 怎么运行

```bash
# 需要 Node 24+（内置 node:sqlite）；零第三方依赖，无需 npm install
node server.js
# 打开 http://localhost:8787
```

配置模型：界面左下角「模型设置」→ 选服务商预设 → 粘贴 Key → 测试连接 → 保存。

## 部署

```bash
docker build -t atoms-demo .        # 仓库已附 Dockerfile
docker run -p 8080:8080 -e STORAGE=sqlite atoms-demo
```

免费的容器托管平台磁盘是临时的，云端请用 `STORAGE=redis` + Upstash REST（仓库附 `render.yaml`）。

## 已知限制

详见 `docs/设计说明.md` 的「暂未完成」与「如果继续投入时间」。要点：账号体系很轻（无邮箱验证与找回密码）、`/api/data` 未限流、静态质检不是 AST 级校验、生成物只支持单文件形态、界面配置的模型 Key 是平台级共享的。

## 归档内容

`atoms-demo-v1.0.0.zip` 为仓库在 `v1.0.0` 标签处的源码快照，含：

- `src/` + `server.js` + `public/`：全部应用代码（零第三方依赖）
- `docs/`：设计说明、部署说明（Windows / Linux）、版本说明、9 张界面截图
- `deploy/`：Windows 服务脚本、systemd 单元、Nginx 反向代理配置、Docker Compose、SQLite 备份脚本
- `tools/`：端到端冒烟测试、生成器测试、真实模型验收、模型连接诊断
- `Dockerfile` / `render.yaml` / `.env.example` / `README.md`

**归档中不包含**：`.env`（你的模型配置）、`data/`（本地数据库，含账号与项目数据）。这两项在 `.gitignore` 中被排除，因此密钥不会随归档外泄。
